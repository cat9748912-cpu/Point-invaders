Point Invaders is a browser-based, high-performance arcade network hub that bridges classic 2D neon vector designs with real-time 3D cyberpunk simulation mechanics. Developed as a comprehensive single-page web environment, the application integrates an expansive catalog of thirty-one custom mini-games, an asynchronous multiplayer duel ecosystem, live scoreboards, and persistent progression loops. By bypassing heavy server-side handshakes in its guest state and utilizing localized state machine vectors, the platform provides immediate runtime execution directly inside the browser client environment. This document serves as the project's definitive README essay, detailing the engineering choices, structural patterns, and game execution models that define Point Invaders.   
The core differentiator of Point Invaders is its dynamic, hot-swappable rendering pipeline. Users can shift the entire interface between two visual modes instantly without requiring account logout or state disruption:2D Classic Mode: A flat, neon-accented vector aesthetic built to optimize CPU cycles and run seamlessly across lower-powered client hardware. It relies on explicit canvas or styled DOM nodes to maintain responsiveness.3D Cyberpunk Mode: An immersive, high-draw graphical tier introducing spatial depth, camera bloom, real-time lighting arrays, and chrome finishes. Designed to extract maximal performance from modern GPUs, it translates traditional 2D game loops into a fully volumetric layout.State Management and Guest ProgressionThe platform uses an un-authenticated, local-first progression model to eliminate onboarding friction. When an operative initiates a session as a guest, their points, credits, profile levels, and system upgrades are bound to the browser's persistent sandbox storage.This state can be permanently mirrored to a centralized ledger at any time via the Account Synchronization protocol, which wraps local variables into a unified username and password profile without resetting active multipliers or leaderboards.
The point generation loop in Point Invaders is governed by the System Stability configuration. Operatives can manually adjust the operational limits of the host runtime environment, trading stability for mechanical scaling vectors:Safe Mode & Stable Core: Standard multipliers (1.0x PTS) ensuring baseline difficulty curves and predictable game state updates.Overclock & Meltdown: High-risk variables that accelerate game-loop processing speed, introduce strict failure windows, and aggressively scale point distributions.This matrix interfaces directly with the Chaos Protocol, an optional modifier engine that injects random handicaps or windfalls before the execution of a mission, forcing players to dynamically alter their strategies mid-run.
The application establishes a closed-loop economy driven by two primary assets: Points (PTS) and Credits (CR). Points measure historical rank and tier placement, whereas Credits serve as the functional currency within the built-in Black Market module.A programmatic exchange interface allows operatives to convert assets at a fixed ratio (100 PTS = 1 CR) to acquire visual customizations, custom cursors, layout skins, world environment styles, and distinct audio packages known as Music Drive
Point Invaders splits its operational modes across several campaign vectors, including a twenty-chapter single-player campaign against "The Glitch," a multi-stage Boss Rush mode, a local multi-user Party Mode, and an Endless Protocol lane that removes spatial boundaries and score caps.The ecosystem features thirty-one specialized game modules categorized by cognitive and mechanical intent:Reflex and Kinetic ExecutionClick Frenzy: A pure throughput test requiring rapid input registration within a constrained ten-second boundary.Neon Nebula: The signature vertical defense engine requiring continuous target acquisition against descending cluster waves.Dodge Cores & Coolant: Precision inertia simulators that challenge users to guide single nodes through bouncing firewall vectors and narrow cooling shafts.Reaction Time: A strict millisecond latency test monitoring state transitions across the core terminal screens.

To maintain low execution latency, the arena supports multiple duel layouts (1v1 Duels, 2v2 Squads, and Co-Op Grids) using a unified synchronization interface:Quick Match: Drops the operative into the nearest available open node room or provisions a synthetic droid placeholder if the matching queue remains quiet.Room Codes: Generates a unique four-character hash identifier allowing users to link specific remote clients to the same instance vector.Replay Encoding: The engine contains a native telemetry tracker that stamps game inputs, time variables, and scores directly into exportable replay codes, facilitating cross-platform challenge tracking and validation.
Beyond the mission grid, the hub carries a set of standing lanes. The Daily Hack seeds one mission a day, the same for every operative, with a board of its own, and the Weekly Anomaly holds one mission under a fixed set of modifiers for a week. The Brick Lab is a level editor with a public Gallery and a Level of the Day, and a level travels as a link. Open World flips any mission, and most modes, into a borderless free-roam version of itself. Challenge links carry a finished run to a friend: "Beat My Ghost" replays the sender's run on the receiver's board. Heat lets an operative choose their own hazards in exchange for more pay, seasonal events add a limited shelf to the market, and every mission awards medals, grid records, wearable titles and a share of three daily contracts that pay credits.
Recent additions: a Codex of story entries unlocked by the campaign; Prestige, a Reboot at level 25 in exchange for a permanent bonus; cosmetic Companions that follow the player's marker; a Campaign Speedrun against a single clock; Glitch Run, a branching roguelike across the operative's own unlocked missions with rule-bending relics; Bounties, credits staked on beating a named score; Crews, up to six saved operatives ranked together every week; eight-seat single-elimination Tournaments in the Network Arena, with droids in the empty seats; play statistics in the Dossier; guest profiles that live in the browser and leave the boards while the guest is away; and a full guided tutorial, narrated by ARC, that can be skipped, resumed and replayed from Settings. In 3D mode the hub itself is a place to fly through: the Flight Deck puts the operative in their Neon Nebula interceptor, seen from a chase camera, between a Solo Missions station and an Events arena. Every mission is a beacon and every mode a gate; flying up to one pops its card, and the boards, dials, loadouts and settings ride in the deck's drawers. The equipped World theme reaches the deck too — its colours in the sky, and its bodies and life: the Orbital Deck's ringed giant and black hole, the Synth Desert's striped sun, Deep Net's jellyfish — and the Graphics setting applies there as in every round. The first time a player flies it, ARC gives a short FLIGHT TRAINING lesson on the deck itself — flying, the autopilot, the stations, the cards, the navigator and the drawers — which Settings → 3D HUB or the navigator brings back. The 2D hub is unchanged, and Settings can switch the 3D hub back to the classic list.
